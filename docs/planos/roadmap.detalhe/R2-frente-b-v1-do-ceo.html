Como o v1 fechou

A prova final (R21-A, 2026-07-16) rodou as pernas (a)–(f) com motor real. Achou o bug #1 (DONE fantasma — o run de issue não tinha compositor) mais 4 achados. O dono decidiu: o v1 fecha; o que sobrou vira o roadmap de ajustes.
